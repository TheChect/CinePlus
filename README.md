# Cine+

Página web de **Cine+**, una tienda de renta de películas en formato físico (DVD, Blu-ray y 4K) pensada para un público retro y de nicho que prefiere lo físico.

Proyecto Integrador de Aprendizaje (PIA) de Programación Web · FIME UANL · Grupo 217, hora N2.

## Tecnologías

- HTML, CSS y JavaScript
- PHP
- MySQL (XAMPP)
